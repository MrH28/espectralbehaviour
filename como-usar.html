Como usar

Instalação, dados e execução do pipeline.

Instalação

pip install -r requirements.txt

Baixe os arquivos: requirements.txt · config.py · utils.py · gerar_dados_sinteticos.py

Notebooks: 01 · 02 · 03 · 04 · 05

Execução

Abra os notebooks na ordem (01 a 05) e execute todas as células. Cada notebook lê os arquivos salvos pelo anterior na pasta resultados/, e as figuras vão para resultados/figuras/. Execute sempre a partir da pasta do projeto, onde estão os notebooks e o config.py.

Dados do Saturin

Os notebooks usam dados/raw_nir_data_Saturin.csv, com ID_Unico como identificador e Clay_gkg como variável-alvo. O arquivo raw_mir_data_Saturin.csv é a fonte MIR alternativa. Os CSVs usam codificação latin1, têm uma coluna índice vazia e bandas espectrais com nomes numéricos em ordem crescente. MAX_AMOSTRAS em config.py limita a amostra aleatória reprodutível. Os CSVs (cerca de 1,4 GB) não são distribuídos neste site.

Não há arquivo de amostras novas sem análise laboratorial; por isso o notebook 05 executa as visualizações e métricas de validação e informa que a predição de novas amostras foi ignorada.

Usando outro banco

  1. Coloque o arquivo em dados/ com uma coluna identificadora, as colunas de atributos e uma coluna por comprimento de onda, nomeada pelo valor em nm (350, 351, …), em ordem crescente.
  2. Em config.py, ajuste ARQUIVO, COL_ALVO e, se as colunas espectrais tiverem prefixo (por exemplo X350), PREFIXO.
  3. Revise WL_MIN, WL_MAX, SG_JANELA, K etc. conforme o sensor e os dados.

Dados sintéticos

gerar_dados_sinteticos.py cria um banco no formato da BSSL para praticar. Os espectros têm feições simuladas perto de 1400, 1900 e 2200 nm, ligadas à argila. Os dados são bem comportados e o desempenho é muito mais alto do que com dados reais; os números obtidos com eles não são resultados científicos. Para usá-los, aponte ARQUIVO e ARQUIVO_NOVAS para os arquivos gerados em config.py.
